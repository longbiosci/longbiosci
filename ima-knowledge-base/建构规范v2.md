## 二、主轴一 · 发表时间标签与回溯顺序

### 2.1 年份标签
- 标签格式 `Y{四位年份}`，取**首次公开发表年份**（预印本取 posted 年份；期刊论文取 online 年份；专著取版次年份）。
- 每年份段内再分四类**文献类型**，优先级从高到低：
  1. **奠基文献**（奠基性原始研究，如 Hayflick 1965、Kenyon 1993）
  2. **权威综述**（Nature Reviews / Cell / Annual Review 级别）
  3. **里程碑原始研究**（顶刊正刊、指南/共识）
  4. **最新进展**（预印本、当年新刊）

## 六、质量红线（不可越）

1. **数据真实可溯源**：年份、DOI、期刊、作者一律来自 Crossref / 期刊官网 / 总台账，**禁止推测与编造**。解析不到就写"未解析"，不许填"近似值"。
2. **元数据核验**：Crossref 标题检索相似度 < 0.75 的条目，进「待人工复核」清单，不直接采信。
3. **去重键**：`DOI`（无 DOI 用 `media_id`）。跨层、跨期重复绝不重复计数。
4. **同一文献不重复入库**：新增前必须先比对共享库现有 126 条 + 总索引，命中即跳过。
5. **全文口径**：用户已定「**不限 OA，尽量取全文**」。凡取得全文的必须归档进共享库；确实取不到的，在索引「全文可得性」列写明 **仅元数据**，不得虚构。
6. **临床试验**一律以 ClinicalTrials.gov 等官方来源为准。

#### 6.1a 通道故障的处置纪律（2026-10-12 R4 定）

| 现象 | 判读 | 正确处置 |
|---|---|---|
| `search` 与 `fullTextXML` **同时** 5xx（含历史上成功过的 PMCID 也失败） | **服务侧瞬断** | **退避重试**（6s×n 递增，最多 6 次）。R4 实测服务端全局 503 约 30 分钟后自行恢复 |
| `fullTextXML` 对某 PMCID 返回 **500**，而同期其它 PMCID 正常 | 该条**无 OA 全文**（仅作者稿/仅扫描件） | 判「仅元数据」，不重试 |
| `fullTextXML` 端点对某 PMCID **不存在** | 该条**无 PMC 记录** | 判「仅元数据」 |
| Unpaywall 返回 200 且给出 `best_oa_location` | **只代表「发现」，不代表「可达」** | **必须实测该 URL**；R4 实测其指向的 rupress PDF 为 403 |

#### 6.1c `media_id` 取号纪律（2026-10-12 R4 新增）

`PENDING-R{n}-NN` 的 `n` **曾按「报告轮次号」取，已发生两次历史占用**（R2 轮用 `PENDING-R4-01~12`、
R3 轮用 `PENDING-R5-01~12`）。R4 轮因此改取 `PENDING-R6-01~13`。

→ **每轮取号前必须先对全库 `media_id` 做唯一性校验**（`collections.Counter` 查重，重复即换号），
不得仅凭轮次号直接编号。取号理由须写入该条 `ovr_note`。

4. 全文可得性标 **「速递层已下载 PDF（共享库归档状态待通道复测）」**——

## 八、进度看板口径

每轮结束后更新三个数字，写入索引的「缺口与下一步」工作表：

1. **库内总篇数**（共享库实测 `knowledge_total_size`）
2. **已著录篇数 / 著录率**（= 已著录 ÷ 总篇数）
3. **年份×标志矩阵的填充格数 / 总格数**（`7 年份段 × 14 标志 = 98 格`，每格 ≥1 篇记为已填充）

> **"数据库做完整"的验收标准** = 98 格全部填充 + 97 篇以上著录率 100% + 无 `H99` 待归类条目。
