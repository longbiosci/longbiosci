老年人内嗅皮层的「网格信号」变弱，是表征不稳了，不是没了

来源：bioRxiv（neuroscience） · 预印本：Temporal instability weakens entorhinal grid-like coding in older adults · DOI 10.64898/2026.10.15.759328 · 通讯 Vladislava Segen（德国神经退行性疾病中心 DZNE） · 来源：《预印本速递》2026-10-22 期（摘要级，全文未获取）

一句话结论：在 85 名老年人的虚拟现实导航 + fMRI 实验中，内嗅皮层「六向信号」随老化变弱，反映的是网格表征在时间上不稳定（跨 run 的方向模式不可复现），而不是表征缺失；左侧后内侧内嗅皮层（pmEC）的稳定性越高，物体-位置记忆越好。

⚠️ 本文为预印本，未经同行评审；本站依据官方摘要撰写（源站封锁，全文未获取），结论可能在正式发表时变更。

这项研究想回答什么

网格细胞负责空间导航的「坐标系」，人类 fMRI 里对应内嗅皮层的六向（60° 周期）信号。既往发现老年人该信号变弱，但「变弱」有两种截然不同的含义：表征退场（没法救）或表征不稳(可以练)。本文在老年人内部直接检验哪种解释成立。

核心发现

  • 六向朝向稳定性（方向特异性活动模式的跨 run 可复现性）与 pmEC 六向信号强度相关。
  • 左侧 pmEC：稳定性越高，物体-位置记忆越好。
  • 年龄本身与局部结构指标均不能解释这些个体差异——「表征稳定性」比「实际年龄」更有解释力。
  • 压后皮层的绝对朝向稳定性与左 pmEC 相关，中介分析支持其经 pmEC 稳定性间接影响六向信号。

证据边界

  1. 纯老年人队列（N=85），无青年对照，摘要未给年龄范围与方差；「老年人内部差异」推到「老化效应」需谨慎。
  2. 记忆关联为相关/中介设计，无因果干预；六向信号作为网格细胞的 fMRI 替代指标本身仍有争议。
  3. 具体效应量（相关系数、中介效应值、p 值）摘要未给，待补全文。

为什么值得关注

它把「老化导致神经表征退化」精细化成「稳定性下降，而非信号消失」——如果瓶颈是不稳定而非缺失，稳定性就是潜在可训练的靶点（导航训练、睡眠、神经调控都有入手处）。对「老化认知衰退是否可逆」这条叙事，这是一个方向性的证据点。
