SIRT1 的另一份工作：把 L1 跳跃基因按在异染色质里，按不住就触发衰老

来源：Aging Cell（2026，25(9): e70689）· 上海市第一妇婴保健院 / 同济大学 Wang X 等，通讯 Geng A · 论文：SIRT1 Silences L1 Retrotransposons by Stabilizing Heterochromatin-Modifying Complexes · DOI 10.1111/acel.70689

SIRT1 是长寿研究领域出镜率最高的分子之一，但它的具体工作内容一直有点含糊：「去乙酰化酶」「代谢感受器」「延寿因子」——这些标签都对，却都没说清它在基因组层面到底做了什么。这篇 Aging Cell 论文给了一个相当具体的答案：它负责按住 L1 逆转座子。

L1 为什么必须被按住

LINE1（L1）是人类基因组里唯一还活跃的自主型逆转座子，约占基因组的 17%。它在年轻细胞里被异染色质牢牢封住；随着年龄增长，这层封印逐渐松动，L1 开始转录、逆转录，产生胞质 DNA——而胞质 DNA 正是 cGAS–STING 的激活信号，最终通向炎症与细胞衰老。

发现：SIRT1 是这套封印的维护者

  • SIRT1 富集于 L1 的 5′-UTR，且在静息态细胞中富集增加；
  • 它增强 Lamin B1 与 KAP1 之间的互作，提高抑制性标记 H3K9me3，从而沉默 L1 转录；
  • SIRT1 缺失时，Lamin B1–KAP1 互作明显降低、二者在 L1 5′-UTR 的定位减少，L1 转录升高；
  • L1 去抑制 → 激活 cGAS–STING → 触发细胞衰老。

机制链可以概括为：SIRT1 → 招募 Lamin B1/KAP1 → H3K9me3 升高 → L1 沉默 → 基因组稳定 → 延缓衰老；缺失时则走 L1 → cDNA → cGAS–STING → I 型干扰素 → 衰老。

最有转化含义的一点：3TC 能救

作者进一步验证，SIRT1 缺失引发的衰老可被逆转录酶抑制剂 3TC 挽救。3TC（拉米夫定）是已获批多年的抗 HIV 药物，安全性数据充分。

这意味着 L1 抑制不是一个「等待新药」的方向——现成的、已获批的分子就是可用的工具。本站此前记录过抗逆转录病毒药物降低健康人生物学年龄的概念验证研究（见延伸阅读），两者在机制上正好互相衔接。

与「cGAS 敲除反而早衰」的关系

本站记录过一项反直觉结果：cGAS 敲除小鼠呈现早衰，机制同样是 LINE1 去抑制。两条研究放在一起看，指向同一个更上层的结论：真正决定衰老走向的是「L1 有没有被按住」，而不是 cGAS 活性的高低。cGAS 只是 L1 泄漏的下游读出口；把读出口堵掉，泄漏本身还在，反而失去了核内的看家功能。

局限

  • 3TC 的挽救仅在细胞层面验证，体内效果未报告——这是本条从「机制好看」到「可能有用」之间最大的缺口。
  • 主要证据来自细胞系，缺少在体衰老模型与寿命数据。终点是衰老标志，不是寿命。
  • SIRT1 激活剂（白藜芦醇类等）的转化争议未被涉及——「提升 SIRT1 活性」与「SIRT1 正常表达」不是一回事，不能从本条直接推出补充 SIRT1 激活剂有效。
  • 摘要层面未提供可引用定量：L1 转录变化幅度、H3K9me3 变化、3TC 挽救的效应量均待补全文。本文不给出任何具体数字。

B 级证据分级：B 级（同行评议临床前研究，主要为动物模型）

本文核心结论来自动物模型或体外细胞学，属临床前证据，不能外推至人体。「延长健康寿命」「改善功能」等表述在小鼠中的意义，与人类临床结局之间仍有距离。
