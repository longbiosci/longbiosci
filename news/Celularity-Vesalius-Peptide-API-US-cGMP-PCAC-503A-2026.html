Celularity × Vesalius 建美国本土多肽 API 终段产能：一份把监管假设写进条款的商业合同

来源：来源：SEC 8-K 附件 99.1 · https://www.sec.gov/Archives/edgar/data/1752828/000149315226049203/ex99-1.htm · 法规原文 21 CFR 216.23：https://www.ecfr.gov/current/title-21/chapter-I/subchapter-C/part-216/section-216.23

数据日期 2026-10-29 · 生成时间 2026-10-30 05:30　｜　行业情报周报 2026-W44 第三次运行（任务 7762986，周一/三/五 01:30 班）

协议要点

  • 双方：Celularity Inc.（NASDAQ: CELU）× Vesalius Longevity Labs Inc.
  • 类型：独家生产与供应协议（BD / 产能型，非股权融资），对价未披露
  • 内容：在新泽西 Florham Park 工厂承担多肽原料的下游纯化、加工、分析与放行，建立美国本土首个 Peptual® 多肽 API 终段生产与供应平台，批次级可追溯
  • 关键条款：若 FDA 依 PCAC 建议把多肽加入 503A 可 compounding 散装物质名单，双方即向持牌美国 compounding 药房供货
  • 明确排除：GLP-1 受体激动剂及其他减重多肽
  • 背景动因：FDA 已公开提示未经核实的境外来源多肽 API的质量与溯源风险
  • 时间：SEC 8-K 附件 99.1，2026-10-29

三方角色：一条「科学信誉 + 供应链合规」的双轨

同一份 8-K 还披露了 Vesalius 的人事配置：Micheal Roizen, M.D.（此前任 克利夫兰诊所健康中心 Wellness 主任）出任首席科学顾问， Pradeep Albert 任 CEO。一家多肽长寿品牌把「前克利夫兰诊所健康中心主任」 放在首席科学顾问位，同时配本土 cGMP 产能——科学信誉与供应链合规被打包出售，这是本期最典型的商业设计。

为什么这条要单列

一家纳斯达克挂牌的「再生长寿」公司把营收预期挂在一份尚未发生的监管决定上。 这不是隐喻：合同文本里写的是条件句。对研究者而言，它的情报价值在于—— PCAC 对多肽散装物质的处置，已经有人用真金白银的产能押注了。

局限与待核实

  • 对价、供货量、期限均未披露，仅知为收入型合作
  • 触发条件尚未发生：FDA 是否采纳 PCAC 建议、何时采纳，无公开日期
  • 多肽类干预的临床证据基础未在 8-K 中讨论，本协议只解决供应链与合规，不构成疗效主张

B 级证据分级：B 级（同行评议临床前研究，主要为动物模型）

本文核心结论来自动物模型或体外细胞学，属临床前证据，不能外推至人体。「延长健康寿命」「改善功能」等表述在小鼠中的意义，与人类临床结局之间仍有距离。
