# 长寿证据链 · 打假与证伪

## 开场

欢迎来到《长寿证据链》。今天这期要讲的不是某个新分子，而是一个更常被忽略的问题：当一篇论文告诉你「我们用人工智能筛出了延寿化合物，准确率百分之八十」，这句话到底值多少钱。数据日期是二零二六年十月二十二日十八点三十二分，节目生成于二零二六年十月二十八日。本期所有结论均来自站内已核实文章，来源清单在节目末尾。

## 第一段：问题从哪来

延寿化合物的实验筛选成本极高。一条线虫、一只小鼠的寿命实验动辄几个月，能同时测的化合物数量非常有限。所以「先用计算模型排序，再拿排名靠前的去做湿实验」这个思路，在衰老研究里存在了很多年。

但这条路有一个结构性的麻烦。模型要用的输入特征，是化合物与蛋白质之间的互作关系；而这类数据本身是稀疏的、也是不确定的。常用的 STITCH 数据库给出的并不是「这个化合物和这个蛋白到底结不结合」，而是一个预测出来的互作概率。也就是说，喂给模型的不是事实，是另一层模型的输出。

于是真正的问题被拆成了两层。第一层：这个连续的概率值，是原样当连续特征用，还是卡一个阈值变成「结合或不结合」的二元特征？第二层，也是更关键的：这个技术选择，会不会连带改变「模型认为哪些蛋白重要」？后者才是很多使用者真正想要的东西——不少人拿这类模型来反向提名机制靶点，也就是反过来问「模型觉得哪些蛋白决定了延寿」。如果换一种数据表示方式，提名出来的靶点名单就变了，那这份名单的分量就要重新掂量。

## 第二段：证据长什么样

这是一篇预印本，实验完全在计算层面完成。

特征来源是 STITCH 数据库的化合物-蛋白互作。标签是秀丽隐杆线虫中的延寿化合物分类。这里要如实说明：标签来源库与纳入标准，摘要里没有讲，站内标注为待补全文，本节目不做推测。

他们构造了三种特征表示：第一种是连续互作概率，直接用原始数值；第二种是固定阈值零点五的二元特征，也就是概率超过零点五算结合，否则算不结合；第三种是在交叉验证内部选出的优化阈值二元特征——注意这个「在交叉验证内部」很关键，它意味着阈值不是事先拍定的，而是在每一折训练时自己学出来的，避免了用测试集信息回过头去调阈值。

模型用了随机森林和 XGBoost 两种，评估方式是分层十折交叉验证。可解释性部分同时用了 MDI、SHAP、TreeSHAP 和 LIME 四种方法，并且用 Jaccard 相似度去比较不同方法给出的 Top 特征排序是否一致。

结果是这样一组数字。随机森林配固定阈值二元特征，准确率百分之七十八点八四，AUROC 零点七三九一，AUPRC 零点五二零二。XGBoost 配优化阈值二元特征，准确率百分之八十点三六，这是全文最高的准确率。XGBoost 配连续特征，AUROC 零点七六零五，AUPRC 零点五三三二。

可解释性那部分的结果反而更有意思：SHAP 与 TreeSHAP 的一致性最强，在三种 XGBoost 表示方式下给出了完全相同的前十个蛋白特征；而 MDI 与 LIME 未必如此。作者的落点是，应当把分类指标和可解释性放在一起评估，而不是只盯着准确率看。

## 第三段：怎么读

这一期最该记住的数字不是百分之八十点三六，而是零点五二到零点五三。

为什么。准确率是一个会被样本结构撑起来的指标。如果正负样本不平衡——比如非延寿化合物远多于延寿化合物——那么一个什么都不干、把所有化合物都判成阴性的模型，准确率也可以很高。AUPRC，也就是精确率-召回率曲线下面积，对这种不平衡要敏感得多。它接近零点五的水平，说明的问题是：当你把模型排在最前面的那一批候选拿去做实验，里面真阳性的比例是有限的。换句话说，「排名靠前」不等于「大概率是真的」。

第二个折扣是数据来源。标签来自线虫的延寿化合物分类，特征来自预测出来的互作概率，两层都不是直接测量。输入是估计值、输出是分类标签的情况下，模型性能的含义需要格外小心。

第三个折扣来自可解释性本身。三种表示方式下 SHAP 和 TreeSHAP 给出了完全相同的前十蛋白，这听起来是好事；但反过来想，如果换一种特征表示就会换一份靶点名单，那么这份名单反映的是数据预处理的选择，还是生物学？摘要没有回答这个问题，站内也没有补入任何站外推论。

第四个折扣是硬性的：这是预印本，未经同行评审。站内说明本次仅依据官方摘要撰写，bioRxiv 源站对本环境返回了 HTTP 四零三，全文未获取；摘要未给出的地方一律标为待补全文，包括正负样本的数量与比例。所以本期不给出任何「这个模型到底好不好用」的最终判断——只讲这组数字在指标层面意味着什么。

还有一条容易被跳过：摘要里没有给出正负样本数量与比例，而这件事恰恰决定了百分之八十这个准确率能不能被信任。缺这个数，准确率就是一个无法解释的漂亮数字。
